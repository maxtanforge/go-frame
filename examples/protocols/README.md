# 协议接入示例

此包可直接编译、测试，不主动监听端口。业务在路由注册处装配返回的 handler。

- `NewUploadHandler`：每请求创建私有临时文件，完整 DTO 校验后调用业务保存函数；返回前关闭/删除暂存文件。文件路径只在 save 回调内有效，需要持久化时由业务同步复制到最终存储。将认证、授权和上传额度控制挂在业务路由外层。
- `NewXMLCallback`：读取有界原始 XML，调用显式业务验签回调，再解码、校验、处理，最后输出原始文本确认。消息 ID 保持字符串，支持 CDATA。这是明文回调接线示例；微信具体验签算法、重放校验、加密包解密及平台响应要求由业务 SDK/适配层处理，不表示已经完成微信平台联调。

公开回调不使用登录令牌认证，但仍需平台验签。仅把精确方法/路径加入公开路由名单，业务处理成功并完成必要持久化之后才返回确认；重复投递的幂等键由业务维护。若要求 XML 回复，使用 `respond.XML`；默认安全错误仍为 JSON，可在业务协议适配层显式选择平台要求的错误响应。

运行 `go test ./examples/protocols`，使用 httptest、临时目录和伪验签，不连接外部平台。
